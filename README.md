# LearnTrack
LearnTrack is a console-based Student & Course Management System built using Core Java.
It will allow admins to manage:

Students

Courses

Enrollments

The core of the project is a menu-based console application in Main.java:

## Example features:

### Student Management


Add new student

View all students

Search student by ID

Deactivate a student (set active = false instead of deleting)


### Course Management


Add new course

View all courses

Activate/Deactivate a course


### Enrollment Management


Enroll a student in a course

View enrollments for a student

Mark enrollment as completed/cancelled


## 🚀 Getting Started

### 1. Clone the Repository

git clone [https://github.com](https://github.com/vikramnallasamy/LearnTrack)

cd your-repo-name

cd src

### 2. Compile and Run
You can run the application directly from your IDE (such as clicking the **Run** button on your main class file) or via the terminal:

Using javac/java (No build tool):

  javac -d Main.java
  
  java Main
